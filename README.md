# Caffe-Web
### ระบบเว็บไซต์ร้านกาแฟ (Demo Frontend Project)

---

## 1. บทนำ (Introduction)

Caffe-Web เป็นโปรเจกต์ตัวอย่างที่สร้างขึ้นเพื่อพัฒนาและปรับปรุงระบบเว็บไซต์ร้านกาแฟด้วย **HTML, CSS และ Vanilla JavaScript** โดยมีการจัดระเบียบโครงสร้างเว็บไซต์ใหม่ให้เป็นระเบียบตามมาตรฐานเว็บสมัยใหม่ (Clean Architecture) ปรับปรุงความสวยงามของ Layout (Responsive Design) ให้รองรับหน้าจอทุกขนาด และทำการแก้ไขปัญหาข้อผิดพลาดต่าง ๆ (Bugs) เพื่อให้เว็บไซต์ใช้งานได้อย่างถูกต้องสมบูรณ์

---

## 2. วัตถุประสงค์ของโปรเจกต์ (Objectives)

1. เรียนรู้พื้นฐานและการจัดโครงสร้าง Frontend (HTML/CSS/JS) ให้เป็นระบบและสะอาด
2. พัฒนาการออกแบบ Web UI ที่มีสไตล์ คลีนตา และตอบสนองต่อผู้ใช้งาน (UX/UI)
3. ฝึกการแยกสไตล์ส่วนกลาง (global.css) เพื่อลดความซ้ำซ้อนของโค้ด (DRY Principle)
4. ฝึกเขียน Vanilla JS สำหรับการควบคุม Interactive Components (Slider, Form Validation)
5. ฝึกฝนการแก้บั๊กและความถูกต้องของการเชื่อมต่อไฟล์บนสภาพแวดล้อมจริง

---

## 3. โครงสร้างโปรเจกต์ (Project Structure)

│       ├── menu.css         # ตกแต่งหน้าเมนูสินค้า
│       ├── about-us.css     # ตกแต่งหน้าเกี่ยวกับเรา
│       ├── login.css        # ตกแต่งหน้าเข้าสู่ระบบ
│       ├── register.css     # ตกแต่งหน้าลงทะเบียนสมาชิก

│   ├── menu.html            # หน้ารายการเมนูแนะนำและเมนูทั่วไป

│   ├── review.html          # หน้ารีวิวและความเห็นลูกค้า
│   ├── order-admin.html     # หน้าสำหรับผู้ดูแลระบบดูรายการสั่งซื้อ
│   └── template.html        # โครงสร้างต้นแบบสำหรับนำไปพัฒนาหน้าใหม่ต่อ

## 4. คุณสมบัติเด่นของโปรเจกต์ที่ได้รับการปรับปรุง (Key Improvements)

### 📌 โครงสร้างหน้าแรกและระบบนำทาง (Index & Navigation)
*   **Unified Layout**: ปรับเพิ่ม Navbar และ Footer ให้หน้า `index.html` สมบูรณ์และเป็นมาตรฐานเดียวกันกับหน้าย่อยอื่น ๆ
*   **Active Navigation**: มีการไฮไลท์ปุ่มเมนูที่กำลังใช้งานอยู่ (Active Class) เพื่อช่วยบอกผู้ใช้ว่ากำลังอยู่ในหน้าใดของเว็บไซต์

### 📌 ระบบสไลเดอร์และคอมโพเนนต์ (Interaction & Sliders)
*   **Dynamic Measurement**: ปรับสคริปต์สไลเดอร์ใน `home.js` และ `about-us.js` ให้คำนวณความกว้างภาพขณะเลื่อนแบบ Real-time รองรับหน้าจอคอมพิวเตอร์และมือถือได้ยืดหยุ่นขึ้น
*   **Auto-slide Reset**: ระบบจะตั้งเวลานับถอยหลังใหม่ทุกครั้งที่ผู้ใช้กดปุ่มเปลี่ยนสไลด์เอง ป้องกันปัญหาสไลด์เลื่อนเร็วเกินไปเมื่อกดคลิกถถี่ ๆ

### 📌 หน้าตรวจสอบสมัครสมาชิก (Form Validation)
*   **Interactive Validation**: หน้า `register.html` ได้เชื่อมสคริปต์ `register.js` เพื่อเช็คความถูกต้องของข้อมูล (ความยาว Username, รูปแบบ Email/เบอร์โทร, การเลือกวันเกิดและเพศ) ปุ่มสมัครสมาชิกจะปลดล็อกอัตโนมัติก็ต่อเมื่อกรอกข้อมูลถูกต้องครบถ้วนเท่านั้น

### 📌 การแสดงผลและการตอบสนอง (Responsive Design & Clean CSS)
*   **Modern Layout Grid**: ปรับปรุงหน้า `menu.html` และ `review.html` ให้แสดงผลแบบการ์ดจัดวางด้วย CSS Flexbox/Grid ที่สวยงาม คลีนตา มีเอฟเฟกต์การซูมเมื่อเอาเมาส์ไปชี้ (Hover effect)
*   **Global Reset**: นำระบบ CSS ย่อยที่ซ้ำซ้อนในทุกหน้าออก แล้วมารวบไว้ที่ `global.css` เพื่อลดขนาดไฟล์และทำให้การจัดหน้าสอดคล้องกันทั้งเว็บไซต์

## 5. รายการแก้ไขบั๊กสำคัญ (Bug Fixes Summary)
1.  **aboutus3.jpg**: แก้คำผิดชื่อรูปภาพจาก `abuotus3.jpg` (เดิมในเครื่อง) เป็น `aboutus3.jpg` เพื่อแก้ปัญหาการโหลดรูปภาพสไลด์ที่สามล้มเหลว
2.  **CSS Unit Typo**: แก้ไขคำสะกดหน่วยใน `promotion.css` จากเดิม `width: 380x;` เป็น `width: 380px;` ให้รองรับการอ่านขนาดรูปภาพได้ถูกต้องตามมาตรฐาน
3.  **Broken Navigation Links**: เปลี่ยนทิศทางลิงก์นำทางจาก `#` ไปยังหน้า HTML ย่อยจริง ๆ ในโฟลเดอร์ `/pages` ทำให้กดลิงก์ไปหน้าต่าง ๆ ได้สมบูรณ์
4.  **Register Validation Hook**: แก้ไขหน้าสมัครสมาชิกที่สร้างระบบ validation ไว้ใน JS แต่ไม่ได้ระบุเรียกใช้ไฟล์ ส่งผลให้ปัจจุบันสามารถเช็ค input ได้สมบูรณ์แบบ
