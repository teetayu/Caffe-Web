# Caffe-Web
### ระบบเว็บไซต์ร้านกาแฟ (Demo Frontend Project)

---

## 1. บทนำ (Introduction)

Caffe-Web เป็นโปรเจกต์ตัวอย่างที่สร้างขึ้นเพื่อพัฒนาและปรับปรุงระบบเว็บไซต์ร้านกาแฟด้วย **HTML, CSS และ Vanilla JavaScript** 

---

## 2. วัตถุประสงค์ของโปรเจกต์ (Objectives)

1. เรียนรู้พื้นฐานและการจัดโครงสร้าง Frontend (HTML/CSS/JS) ให้เป็นระบบและสะอาด
2. พัฒนาการออกแบบ Web UI ที่มีสไตล์ คลีนตา และตอบสนองต่อผู้ใช้งาน (UX/UI)
3. ฝึกการแยกสไตล์ส่วนกลาง (global.css) เพื่อลดความซ้ำซ้อนของโค้ด (DRY Principle)
4. ฝึกเขียน Vanilla JS สำหรับการควบคุม Interactive Components (Slider, Form Validation)
5. ฝึกฝนการแก้บั๊กและความถูกต้องของการเชื่อมต่อไฟล์บนสภาพแวดล้อมจริง

---

## 3. โครงสร้างโปรเจกต์ (Project Structure)

โปรเจกต์นี้ได้รับการจัดโครงสร้างใหม่แยกโฟลเดอร์ให้ชัดเจนตามหน้าที่ของไฟล์ดังนี้:

```text
Caffe-Web/
│
├── assets/                  # โฟลเดอร์เก็บทรัพยากรหลักของระบบ
│   ├── images/              # รูปภาพประกอบ ไอคอน และโลโก้ร้าน
│   │   └── ...
│   ├── js/                  # ไฟล์ควบคุมการทำงาน (JavaScript)
│   │   ├── home.js          # จัดการสไลเดอร์หน้าแรก
│   │   ├── about-us.js      # จัดการสไลเดอร์หน้าเกี่ยวกับเรา
│   │   └── register.js      # ระบบตรวจสอบข้อมูลก่อนสมัครสมาชิก
│   └── styles/              # ไฟล์ตกแต่งหน้าเว็บ (CSS)
│       ├── global.css       # สไตล์ส่วนกลาง (Reset, Navigation Bar, Footer, Copyright)
│       ├── home.css         # ตกแต่งเฉพาะหน้าแรก
│       ├── menu.css         # ตกแต่งหน้าเมนูสินค้า
│       ├── about-us.css     # ตกแต่งหน้าเกี่ยวกับเรา
│       ├── login.css        # ตกแต่งหน้าเข้าสู่ระบบ
│       ├── register.css     # ตกแต่งหน้าลงทะเบียนสมาชิก
│       ├── queue.css        # ตกแต่งหน้าคิว
│       ├── review.css       # ตกแต่งหน้ารีวิวลูกค้า
│       └── order-admin.css  # ตกแต่งใบเสร็จสั่งซื้อของแอดมิน
│
├── pages/                   # รวบรวมหน้าเว็บย่อยทั้งหมดของระบบ
│   ├── about-us.html        # หน้าเกี่ยวกับเรา
│   ├── login.html           # หน้าเข้าสู่ระบบ
│   ├── register.html        # หน้าสมัครสมาชิก
│   ├── menu.html            # หน้ารายการเมนูแนะนำและเมนูทั่วไป
│   ├── promotion.html       # หน้าแสดงโปรโมชันร้าน
│   ├── queue.html           # หน้าแสดงสถานะคิวลูกค้า
│   ├── review.html          # หน้ารีวิวและความเห็นลูกค้า
│   ├── order-admin.html     # หน้าสำหรับผู้ดูแลระบบดูรายการสั่งซื้อ
│   └── template.html        # โครงสร้างต้นแบบสำหรับนำไปพัฒนาหน้าใหม่ต่อ
│
├── index.html               # หน้าแรกของเว็บไซต์ (Landing Page / Home)
└── README.md                # เอกสารประกอบคำอธิบายโปรเจกต์
```
